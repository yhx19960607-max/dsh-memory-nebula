# 记忆星穹

把 DSH 里聊过的每一轮对话，铺成一张可以旋转、缩放、搜索的银河星图。每个会话是一团星系，每条记忆是一颗星；星与星之间的连线来自共享的关键词。它不只是好看：助手可以随时把记忆搜回来、读出原文。

## 它做什么

- **铺成星图**：读取 `~/.dsh/sessions` 的历史会话，抽掉工具调用、思考过程和系统注入，把「真人发言 + 助手正文」压成一条条记忆。按会话分团，按时间排旋臂，按重要度定星等。
- **读回来用**：提供三个助手工具和一个斜杠指令：
  - `nebula_search`：按关键词搜索全部记忆，返回日期、会话、片段和记忆 id。
  - `nebula_read`：按 id 读一条记忆的完整原文，或按会话 / 日期读一批。
  - `nebula_remember`：把一条值得长期记住的事写进星图（会出现在「手写记忆」星系）。
  - `/nebula`：把最近的记忆摘要递给当前会话，让助手先接上记忆再回答。
- **搜索高亮**：面板里输入关键词，命中的星会脉冲发亮，其余变暗；点击星星看全文。
- **纯本地**：只读本机会话文件，缓存写在 `~/.dsh/memory-nebula/`，不联网、不上传。

## 外观设置

星图右上角「⚙ 设置」里可以调：

- **主题**：星海 / 赛博紫 / 深海青 / 暖金 / 靛蓝 / 极夜，一键换底色和整体色调；也可以自定义底色
- **背景不透明度**：20%–100%，调低会透出 DSH 底层
- **排布**：不规则星云（默认）、球面、圆盘银河、双旋臂、螺旋塔、立方格、圆环，切换时星团会缓动飞过去
- **星图**：星点亮度、节点大小、粒子密度、连线亮度、自转速度（0 就是停转）、呼吸强度（0–200%，控制星星与星核的明暗脉动幅度）
- **流星 / 会话名**：开关（流星是一颗拖着渐隐光尾的小光球，沿关键词连线飞）
- **左侧记忆列表**：开关，也可以点顶栏的「⟨ 列表」直接收起
- **缩放**：滚轮拉近是相机推近而不是简单放大，近处星团会明显放大、远处压暗，越近透视越强

设置存在浏览器 localStorage 里，刷新后保留；「恢复默认」一键回到初始状态。

## 怎么用

1. 重启 DSH（或在插件页启用本插件），左侧栏出现「记忆星穹」。
2. 首次打开会扫描会话并铺图，几秒内完成；之后点「重建」可增量补新会话。
3. 在任意会话里输入 `/nebula`，或直接让助手「搜一下我们之前聊过的 XX」，它会调用 `nebula_search`。

## 已知限制

- 只读已经落盘的会话；正在进行的会话要等落盘后才会出现。
- 关键词用字边界统计自动发现，不做分词模型；个别标签会有噪声。
- 图谱为了可读性按会话限额取样，搜索仍然覆盖全部记忆。
- 星图是 Canvas 2D 手写投影，没有 WebGL 辉光；上千颗星时帧率会下降。
